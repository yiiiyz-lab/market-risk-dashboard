# Market Risk Dashboard

A Python application that simulates the daily workflow of a market risk analyst by analyzing a multi-asset portfolio.

## Features

- Portfolio return analysis
- Historical volatility
- Value at Risk (VaR)
- Expected Shortfall (ES)
- Portfolio exposure
- Stress testing

## Technology

- Python
- pandas
- NumPy
- Plotly
- Streamlit
